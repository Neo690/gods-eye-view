- **The startup console now accounts for what it cannot reach.** A keyboard
  shortcut is not an element, so disabling hosts left the keys calling services
  that were never constructed; the application shortcuts are gated on the scene
  and console phases and answer nothing while either is missing. A stalled chip
  also carries a small mark rather than only a dimmed style, since `title` does
  not exist on a phone.
- **The module-graph watchdog grew the parts a fallback needs.** Its line
  carries a real reload link (the CSP allows it, no script needed), names the
  script the browser failed to load (`main-abc123.js did not load.`), and has a
  second deadline at 30 s for a graph that ran but never reached the new
  `data-boot="ready"` mark — a cover left over a boot that started and stopped
  is no longer silent. Its copy is generated from the catalogs by
  `npm run boot-watchdog:i18n`, so the six locales cannot drift from the
  translations while staying inside one classic script.
- **Device Sweep's inventory does more than fly.** Each entry offers COPY
  ADDRESS without moving the camera, and a NEW chip narrows the list to what the
  last scan added while keeping every device's ring slot. Using an unplaced
  device as the sweep's place was considered and rejected: a LAN device carries
  no coordinates, and inventing one would be a false position.
- **The gate runs in CI.** `Device Sweep browser gate` builds the bundle, serves
  it and runs the same nine browser steps on every pull request, uploading its
  evidence on failure (Neo690, #1372).
