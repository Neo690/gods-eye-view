- **Device Sweep** reads the inventories a desktop already has, not only nmap.
  The row takes an `arp -a` table (Linux, macOS and the Windows three-column
  form), `/proc/net/arp` and a router's DHCP lease list alongside nmap's XML
  (`-oX`), normal and greppable (`-oG`) reports, and a file carrying a single
  address-and-MAC row is refused instead of being read as a one-device
  inventory. The maker behind each MAC, open RTSP and video-recorder ports and
  camera-like host names rank what is found, an unverified MAC prefix stays
  unnamed rather than guessed at, and the ring can be placed from the browser's
  location, one click on the globe or typed coordinates. Nothing is scanned from
  here, the file never leaves the page, and the layer is registered local-only
  so no share link can carry it (Neo690, #1357).
