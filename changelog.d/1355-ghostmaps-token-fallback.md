- GhostMaps recovers from a rejected GitHub token or a rate-limited REST
  client. The public repository needs no credential, so a 401/403 on the
  authenticated tree or commit read is retried once without `Authorization`;
  if the anonymous API still refuses, the watcher reads the same commit's
  rendered tree pages and sizes only the selected KMZ files with pinned HEAD
  requests. A stale dashboard token or a shared datacenter IP no longer
  empties the S2 layer, while a real upstream outage still reports its error
  (Neo690, #1355).
